# 숫자 만들기

- 플랫폼 / 문제 번호: SWEA / 4008
- 문제 링크: 
- 제출 상태: 해결

## 문제 설명
N개의 숫자(3 ≤ N ≤ 12)가 순서대로 주어지고, 숫자 사이에 넣을 연산자(+, -, *, /)의 개수가 주어진다.
주어진 연산자를 모두 사용해 수식을 만들고, 연산자 우선순위 없이 왼쪽부터 계산한다.
나눗셈은 소수점 이하를 버린다.
만들 수 있는 수식의 결과 중 최댓값과 최솟값의 차이를 출력한다.

## 입력 예시
1
5
2 1 0 1
3 5 3 7 9

## 출력 예시
#1 24

## 풀이 방법

스택에 (다음에 쓸 숫자 번호, 현재까지 계산값, 남은 +, -, *, / 개수)를 하나의 튜플로 넣고 사용
모든 숫자를 사용한 상태(idx == N)에서 최댓값과 최솟값을 갱신하고, 스택이 빌 때까지 반복한 뒤 차이를 출력했다.

## 코드 설명
- 시작 상태는 (1, nums[0], +, -, *, / 개수)이다. 첫 숫자는 이미 계산에 들어갔으므로 다음에 쓸 숫자는 1번이다.
- 연산자 개수가 0보다 클 때만 그 연산자를 쓴 새 상태를 스택에 넣는다.
- idx == N이면 최댓값·최솟값을 갱신하고 continue로 다음 상태로 넘어간다.
- 나눗셈은 int(cur / num)을 사용했다.
- 최댓값과 최솟값의 차이는 while이 모두 끝난 뒤 한 번만 계산한다.

## 막힌 점 또는 질문
1. 처음에 나눗셈을 `//`로 계산해서 답이 틀렸다.
   `//`는 음수에서 내림이 되어 -2 // 3 = -1이 되지만, 문제는 소수점 이하를 버리는 것이라 0이 되어야 한다.
   그래서 int(cur / num)으로 바꿨다.
